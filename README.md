\# Spam/Fraud Detection Pipeline (Classical ML)



A robust text classification pipeline built using Python and Scikit-Learn to detect spam SMS messages with optimized decision threshold tuning.



\## Project Overview

\* \*\*Data Source:\*\* SMS Spam Collection Dataset

\* \*\*Feature Extraction:\*\* TF-IDF Vectorization (`max\_features=5000`)

\* \*\*Models Evaluated:\*\* Naive Bayes, Logistic Regression, and Random Forest

\* \*\*Key Focus:\*\* Imbalanced classification and decision threshold tuning to strictly control false positives.
